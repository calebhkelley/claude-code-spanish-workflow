# Instructions for Claude

## Writing style
- Use curly apostrophes in all human-readable text. Straight apostrophes belong only in code.
- Avoid em dashes in written materials.
- Use colons sparingly.
- Make direct, affirmative statements. Avoid "it’s not X, it’s Y" framing.
- Use bold only when it truly matters.
