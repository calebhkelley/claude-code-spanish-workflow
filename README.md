# Claude Code for Spanish Teaching and Sociophonetics

A starter Claude Code setup for language teaching and speech research, by [Caleb Kelley](https://calebhkelley.github.io) (Emory University). Fork it, keep what helps, and rewrite the rest for your own courses.

Inspired by Pedro Sant’Anna’s [claude-code-my-workflow](https://github.com/pedrohcgs/claude-code-my-workflow), which does the same for economics.

## What’s inside

| Folder | Contents |
| :-- | :-- |
| `CLAUDE.md` | Standing instructions for writing, Spanish usage and course style |
| `skills/` | Teaching skills (class materials, activities, readings, grading support) |
| `research-skills/` | Praat scripting, forced alignment, mixed-effects models in R |

## Getting started

1. Fork this repo and clone it to your computer.
2. Open the folder in Claude Code.
3. Tell Claude about your course in two or three sentences and ask it to adapt `CLAUDE.md`.
4. Try one skill on a real lesson before adding more.

## Honest scope

These skills save me time drafting materials and first-pass feedback. I still review every handout, slide and grade myself. The grading skills never receive student names or identifying information.
