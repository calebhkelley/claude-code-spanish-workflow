# Teaching skills

Each skill lives in its own folder with a `SKILL.md` file. Several are written for Emory’s SPAN 201, 202 and 212 and the Contraseña textbook, so expect to adapt course names, unit structure and visual systems to your own program.

| Skill | What it does |
| :-- | :-- |
| `clase-materiales` | Slide decks and lesson plans for a class day, with per-course design systems in `courses/` |
| `actividad-de-sintesis` | Unit synthesis assessments with answer key and rubric |
| `proyecto-materiales` | Unit project materials, from preparation sheet to rubric |
| `en-la-red` | Guided in-class interpretive activities |
| `lector-212` | Reading support for SPAN 212 texts |
| `texto-para-estudiantes` | Student-facing texts at the right proficiency level |
| `espiritu-visual-diapositivas` | Visual style guidance for slides |
| `verbos-frecuentes-espanol` | High-frequency verb lists and practice |
| `spanish-participation-grader` | First-pass feedback on participation reflections |
| `spanish-project-grader` | First-pass feedback on student projects |

Course profiles (`courses/*/profile.md`) are left out because they name colleagues and local files. Write your own from the structure `clase-materiales` describes.
