# SPAN 201 · visual system, provisional

A starting point, not a decision. It is deliberately not SPAN 212’s look, because the two courses should not share a palette and because a language course and a literature course want different slides.

Replace this file and `design.json` as soon as Caleb supplies visual references. Nothing else in the skill changes when that happens.

## What a language course asks of a slide that a literature course does not

- The model sentence is the content. A slide often exists to hold one sentence the students will copy, so type runs larger and lines run shorter than in SPAN 212.
- Contrast pairs carry the grammar. Two columns with one form on each side does more work here than anywhere else.
- Instructions are read off the screen and followed while the instructor talks, so a task slide has to survive being looked at for eight minutes without becoming visual noise.
- Images illustrate vocabulary rather than setting a mood, so the three-up band earns more use than the full-bleed photographic panel.

## The provisional DNA

Keeps the family resemblance to his own materials without copying SPAN 212.

- All-caps titles with a hairline rule under them, as in his own decks, but set slightly larger and with the kicker carrying the unit number rather than a lección title.
- A warmer paper and a softer ink than SPAN 212, so the two courses are distinguishable at a glance across a desk.
- The accent rotates by class meeting, advancing one step through the set each meeting and wrapping around, so adjacent classes look distinct. The set runs teal, ochre, ciruela, musgo, ladrillo and pizarra. Record which accent the next meeting uses in SPAN 201’s project memory. This per-meeting rotation is specific to SPAN 201; SPAN 212 rotates by lección instead.
- The `dos-columnas` and `banda` types do most of the work. `cita` is rare. `oscura` marks the pair or group activity.
- Model sentences go in the display face, which reads as a quotation and separates the sentence to be copied from the instruction around it.
