# Proyecto · Preparación + instrucciones + rúbrica

Caleb runs one Proyecto per Contraseña unit, submitted to a Canvas threaded discussion, with students commenting on classmates’ projects. This skill builds three Word documents for a unit’s project, in his Emory-styled system:

1. The Preparación en clase sheet, the brief in-class planning/borrador work (one page).
2. The student instrucciones, the project itself, posted on the unit’s Canvas discussion.
3. The detailed rúbrica.

Keep the in-class prep and the Canvas project as separate documents. The instrucciones are what students read on Canvas; the Preparación sheet is a class handout. Do not blend them into one file, and do not copy Contraseña/Lingro source lines verbatim when they assume a context that doesn’t apply (e.g. "no suban imágenes aquí todavía…" makes no sense in class, where there is nothing to upload, cut or rewrite such lines).

## Before you draft, gather and confirm

Inputs:
- The Contraseña project draft for the unit (the instructions text, often a .txt or the Contraseña "Proyecto" section). Start from it and improve it; don’t rebuild from nothing.
- The Contraseña detailed rubric PDF for the unit (e.g., Contraseña_Proyecto_Unit_N_Detailed_Rubric). This is the source of truth for the rubric criteria, point values, and wording.
- The unit Vocabulario and Resumen gramatical PDFs, so the instructions point at the unit’s real target vocabulary and grammar.
- The unit’s En la red / class work, so the analytic paragraph can require a concrete in-class detail (see AI resistance).
- Project-memory conventions (span201_fall2026.md, span201_canvas.md, span201_sintesis.md, feedback_glossing.md): projects run as one graded threaded discussion per unit, worth 115 points = 100 (the project) + 15 (commenting on three classmates’ or groups’ projects, 5 each); the flow is borrador in class → síntesis → publicar → comentar.
- The calendar for the borrador date. The Publicar and Comentar due dates usually live on the Canvas discussion, not the calendar, so reference Canvas rather than inventing them.
- caleb-profile for voice.

Confirm with Caleb before building, since these change what you write:
- Pairs or individual? If pairs, one joint submission with a shared grade, or individual submissions? This drives the register (ustedes vs tú) and the "cómo se entrega" section.
- Point scale. Default keeps the Contraseña detailed rubric at /100, with the remaining 15 Canvas points coming from the comentar component. Only change this if he asks.
- Length. Keep the Contraseña minimum word count for the analytic paragraph as given (e.g. ≥125 words). For a pair it is fine as is, because the creative/continuation task is the heavier joint lift, do not inflate it.

## Standing conventions (READ THESE, they are what he corrected)

- Register. Pair instructions in ustedes; individual in tú. Caleb speaks vosotros in class but never asks it of students, so student-facing materials are never in vosotros.
- Glossing discipline (feedback_glossing.md). Directions stay in Spanish. Do NOT gloss every direction into English, that turns a Spanish document into a translation exercise and is bad design in a language course. Gloss English only for: (a) a few genuinely blocking task words, inline in parentheses, e.g. "Anoten (jot down)"; (b) the academic-honesty box, which may be fully bilingual on purpose; (c) proper-name labels of external English resources, e.g. "(Finita Image Bank)". Never gloss the unit’s target vocabulary. Prefer Spanish scaffolds (¿qué pasa? ¿cómo se siente el personaje?) over English.
- No colons to bridge or introduce (his preference). For labeled bullets use a bold-blue label + period, then the sentence, "Publicar. Cada pareja…", not "Publicar: cada pareja…". Same for Recordatorios. Use the `lbullet` helper.
- Other writing prefs: no em dashes in prose (the dialogue raya, is content, and is fine); avoid the "no es X, es Y" contrast frame; curly apostrophes and « » quotes; sparing, intentional bold; in Spanish no Oxford comma, in English use it.
- Dates. From the calendar for the borrador, per meeting pattern; "según Canvas" for Publicar and Comentar. Never invent a date.
- Files live in Proyectos/<Uxx>/. Work on copies, deliver the finished files.

## Academic-integrity + AI resistance (bake into every project)

Caleb’s stance (2026-09-06): the in-class síntesis is the real assessment backstop; the project just needs to lower the payoff of offloading and read as "off" when AI’d. No AI detectors (false-positive harm to strong/heritage students). Policy = tools yes, generators no; consequence = flag for a conversation before grading, not a rubric point penalty (leave rubric criteria wording verbatim). Implement with:

- A Herramientas y honestidad académica box (blue-tint) on BOTH the instrucciones and the rúbrica. Standard text (swap "la pareja"→"el/la estudiante" and ustedes→tú for individual projects):
  - ES: "Este proyecto evalúa la escritura de ustedes, así que el español tiene que ser suyo. Pueden usar el diccionario, el glosario del libro y un conjugador de verbos. No usen traductores automáticos ni programas de inteligencia artificial que escriban o traduzcan oraciones completas, como ChatGPT, DeepL o Google Translate. Escriben por ustedes y no les ayudan a aprender. Si un texto queda muy por encima del nivel de la clase o parece hecho por una máquina, hablaré con la pareja antes de calificar."
  - EN (italic grey, the one bilingual exception): "In English. This project grades your own writing, so the Spanish must be your own. A dictionary, the textbook glossary, and a verb conjugator are fine. Whole-sentence translators and AI generators are not, because they do the writing for you. Work well above course level or that looks machine-generated will prompt a conversation before grading."
- An in-class-detail requirement in the analytic paragraph, tying it to the unit’s own class work (only Caleb’s class produced it): e.g. "Incluyan un detalle concreto de lo que vimos en clase, por ejemplo del [video / lectura / conversación de En la red de la unidad]. Si usan datos, digan de dónde son."
- When the project uses a required image/media set, an image-text coherence ¡OJO! box (cream, gold left bar): "¡OJO! Cada imagen tiene que ir con lo que escriben. Las imágenes y el cuento cuentan lo mismo, en el mismo orden. Una imagen que no va con el texto no cuenta."
- A comentar specificity line: a good comment names something concrete the pair/author wrote, not just the general idea.

## The Preparación en clase doc (one page)

Student-facing, same register. The in-class borrador/planning for the borrador date. Framed as planning (do not claim it is or isn’t graded unless Caleb says). Structure, from the draft’s Preparar steps:
- Título, unit question, a short blue-tint box ("En clase, en parejas") saying they plan today, keep their notes, and write + publish the full project on Canvas later.
- The 2–3 planning steps as Paso 1 / Paso 2 / Paso 3 (miren la fuente y anoten vocabulario; hablen de las preguntas guía; elijan las imágenes/el material y el orden, con una acción y una emoción por imagen). Spanish only; gloss at most one genuinely tricky verb.
- A cream ¡OJO! grammar reminder for the unit’s target grammar (e.g. pret vs imperf).
- A closing line: guarden estas notas; las instrucciones completas y la rúbrica están en Canvas.

## The instrucciones doc (Canvas)

Student-facing. The Preparar steps live in the Preparación sheet, NOT here, the instrucciones only reference that planning happens in class. Structure, built from the unit’s project draft:
- Título and the unit question; a short box stating pairs or individual and how it is graded.
- Descripción (what they will produce), 2–3 short sentences.
- Cómo y cuándo se entrega, as period-label bullets: Preparar (in class, per the borrador date/section), Publicar (to the Canvas discussion, date según Canvas), Comentar (on three other projects, date según Canvas), Valor (100 + 15 = 115).
- The Herramientas y honestidad box (see above).
- Publicar: the actual deliverable. Usually a paragraph with a minimum word count + the in-class-detail requirement + a MODELO, then the main creative task with its explicit requirements (number of images, number of target-grammar instances, dialogue conventions, demonstratives, and so on) + the image-coherence ¡OJO! box + a MODELO + any image-bank or resource link.
- Comentar: each student comments on three projects; "Un buen comentario, en español, hace tres cosas." then three bullets (dice algo concreto que la pareja escribió; hace una conexión con el tema; termina con una pregunta o una idea). Worth 15 points.
- Recordatorios: the unit grammar, dialogue conventions, spelling/accents, and to read the rubric before submitting, period-label bullets, Spanish only.

## The rúbrica doc

Landscape. Reproduce the Contraseña detailed rubric faithfully. Keep its criteria, its point values, its score ranges, and its descriptor wording. Do not soften or rewrite the levels; Caleb wants the official rubric, styled, not a paraphrase.
- Columns: Criterio, Pts, and the four performance levels (Exceeds / Sobresaliente, Meets Strong / Cumple sólido, Meets Minimal / Cumple mínimo, Doesn’t meet / No cumple), each descriptor cell carrying its point range in parentheses.
- Criterion names bilingual (Spanish label, English under it) suit a Spanish class; descriptor text stays as the source has it (usually English).
- A top box stating how it is graded (jointly per pair if applicable; project 100, comentar 15, Canvas total 115).
- The Herramientas y honestidad box after the grid, before the Comentar note. Point values untouched.
- A Comentar note at the foot: three comments at 5 points each, and what a complete comment does.

The reproduced criteria must sum to the rubric’s stated total (100 for the standard Contraseña detailed rubric). Add the column and check before delivering.

## Styling engine

Build the docs with python-docx. Write the helper below to `emorydoc.py` and `import` it; it is the validated Emory system (blue #012169 headings, gold #F2A900 rules, cream #FCF6E7 boxes, blue-tint #EEF1F7 notes, warn #FDF1D8, Calibri). The Preparación and instrucciones use `new_doc(margins=0.8)`; the rúbrica uses `new_doc(margins=0.6, landscape=True)`.

Use `box(..., label=..., fill=TINT)` for info/honesty boxes (blue left bar) and `box(..., fill=CREAM, left=GOLD)` for ¡OJO! cautions (gold left bar). For MODELO boxes, `label='Modelo'`, fill=TINT, body italic. Use `lbullet` for period-label bullets (no colon). If the finished instrucciones spills one orphan line onto a third page, tighten spacing slightly (already set: h2 before ~9, h3 ~6; drop body space_after to ~4) rather than cutting content.

```python
# emorydoc.py
from docx import Document
from docx.shared import Pt, Inches, RGBColor
from docx.oxml.ns import qn
from docx.oxml import OxmlElement
from docx.enum.table import WD_TABLE_ALIGNMENT

BLUE="012169"; GOLD="F2A900"; TINT="EEF1F7"; CREAM="FCF6E7"; WARN="FDF1D8"
GREY="6E6A65"; INK="141414"; HAIR="D8D2CC"

def cell_bg(cell, fill):
    tcPr=cell._tc.get_or_add_tcPr(); shd=OxmlElement("w:shd")
    shd.set(qn("w:val"),"clear"); shd.set(qn("w:color"),"auto"); shd.set(qn("w:fill"),fill); tcPr.append(shd)

def cell_borders(cell, left=None, top=None, bottom=None, right=None, allc=None):
    tcPr=cell._tc.get_or_add_tcPr(); tb=tcPr.find(qn("w:tcBorders"))
    if tb is None: tb=OxmlElement("w:tcBorders"); tcPr.append(tb)
    def setb(side, spec):
        if spec is None: return
        e=tb.find(qn("w:"+side))
        if e is None: e=OxmlElement("w:"+side); tb.append(e)
        sz,color=spec
        e.set(qn("w:val"),"single"); e.set(qn("w:sz"),str(sz)); e.set(qn("w:space"),"0"); e.set(qn("w:color"),color)
    if allc:
        for s in ("left","top","bottom","right"): setb(s, allc)
    setb("left",left); setb("top",top); setb("bottom",bottom); setb("right",right)

def no_table_borders(table):
    b=OxmlElement("w:tblBorders")
    for edge in ("top","left","bottom","right","insideH","insideV"):
        e=OxmlElement("w:"+edge); e.set(qn("w:val"),"none"); b.append(e)
    table._tbl.tblPr.append(b)

def keep_together(par):
    pPr=par._p.get_or_add_pPr()
    for tag in ("w:keepNext","w:keepLines"):
        el=OxmlElement(tag); el.set(qn("w:val"),"true"); pPr.append(el)

def keep_lines(par):
    pPr=par._p.get_or_add_pPr(); el=OxmlElement("w:keepLines"); el.set(qn("w:val"),"true"); pPr.append(el)

def space(par, before=None, after=None, line=None):
    pf=par.paragraph_format
    if before is not None: pf.space_before=Pt(before)
    if after  is not None: pf.space_after =Pt(after)
    if line   is not None: pf.line_spacing=line

def run(par, text, size=11, bold=False, italic=False, color=None, font="Calibri", caps=False, spacing=None):
    r=par.add_run(text); r.bold=bold; r.italic=italic; r.font.size=Pt(size); r.font.name=font
    if color: r.font.color.rgb=RGBColor.from_string(color)
    if caps:
        rpr=r._r.get_or_add_rPr(); sc=OxmlElement("w:smallCaps"); sc.set(qn("w:val"),"true"); rpr.append(sc)
    if spacing is not None:
        rpr=r._r.get_or_add_rPr(); sp=OxmlElement("w:spacing"); sp.set(qn("w:val"),str(spacing)); rpr.append(sp)
    return r

def para(doc, text=None, **kw):
    p=doc.add_paragraph()
    if text is not None:
        run(p, text, **{k:v for k,v in kw.items() if k in ("size","bold","italic","color","font","caps","spacing")})
    return p

def new_doc(margins=0.8, landscape=False):
    doc=Document(); st=doc.styles["Normal"]
    st.font.name="Calibri"; st.font.size=Pt(11); st.font.color.rgb=RGBColor.from_string(INK)
    sec=doc.sections[0]
    if landscape:
        from docx.enum.section import WD_ORIENT
        sec.orientation=WD_ORIENT.LANDSCAPE; sec.page_width, sec.page_height=Inches(11), Inches(8.5)
    for m in ("top_margin","bottom_margin","left_margin","right_margin"): setattr(sec, m, Inches(margins))
    return doc

def gold_rule(par, size=16):
    pPr=par._p.get_or_add_pPr(); pbdr=OxmlElement("w:pBdr"); bottom=OxmlElement("w:bottom")
    bottom.set(qn("w:val"),"single"); bottom.set(qn("w:sz"),str(size)); bottom.set(qn("w:space"),"4"); bottom.set(qn("w:color"),GOLD)
    pbdr.append(bottom); pPr.append(pbdr)

def kicker(doc, text):
    p=doc.add_paragraph(); space(p, before=2, after=1); run(p, text.upper(), size=9, bold=True, color=BLUE, caps=True, spacing=30); keep_lines(p); return p

def h1(doc, text):
    p=doc.add_paragraph(); space(p, before=2, after=4); run(p, text, size=22, bold=True, color=BLUE); keep_lines(p); return p

def h2(doc, text, rule=True):
    p=doc.add_paragraph(); space(p, before=9, after=5); run(p, text, size=14, bold=True, color=BLUE); keep_together(p)
    if rule: gold_rule(p, 16)
    return p

def h3(doc, text):
    p=doc.add_paragraph(); space(p, before=6, after=2); run(p, text, size=11.5, bold=True, color=BLUE); keep_together(p); return p

def box(doc, lines, fill=TINT, left=BLUE, left_sz=24, label=None, label_color=None):
    # lines: list of (text, kwargs-dict) or plain str. One-cell callout table.
    t=doc.add_table(rows=1, cols=1); t.alignment=WD_TABLE_ALIGNMENT.LEFT; no_table_borders(t)
    c=t.cell(0,0); cell_bg(c, fill)
    if left: cell_borders(c, left=(left_sz, left))
    c.width=Inches(6.6)
    tcPr=c._tc.get_or_add_tcPr(); mar=OxmlElement("w:tcMar")
    for side,val in (("top",90),("bottom",90),("start",150),("end",150)):
        e=OxmlElement("w:"+side); e.set(qn("w:w"),str(val)); e.set(qn("w:type"),"dxa"); mar.append(e)
    tcPr.append(mar)
    first=c.paragraphs[0]; first.text=""; made=False
    if label:
        space(first, after=2); run(first, label.upper(), size=8.5, bold=True, color=label_color or left, caps=True, spacing=20); made=True
    for item in lines:
        p = c.add_paragraph() if made else first; made=True
        space(p, after=2, before=0)
        txt, kw = item if isinstance(item, tuple) else (item, {})
        run(p, txt, **kw)
    return t

def bullet(doc, text, level=0, **kw):
    p=doc.add_paragraph(); p.paragraph_format.left_indent=Inches(0.28+0.25*level)
    p.paragraph_format.first_line_indent=Inches(-0.16); space(p, after=2, before=0)
    run(p, "•  ", size=11, color=GOLD, bold=True)
    run(p, text, **{k:v for k,v in kw.items() if k in ("size","bold","italic","color","font")}); return p

def lbullet(doc, label, text):  # period-label bullet, NO colon (his preference)
    p=doc.add_paragraph(); p.paragraph_format.left_indent=Inches(0.28)
    p.paragraph_format.first_line_indent=Inches(-0.16); space(p, after=2, before=0)
    run(p, "•  ", size=11, color=GOLD, bold=True)
    run(p, label+". ", size=11, bold=True, color=BLUE); run(p, text, size=11); return p

def numbered(doc, n, text, **kw):
    p=doc.add_paragraph(); p.paragraph_format.left_indent=Inches(0.32)
    p.paragraph_format.first_line_indent=Inches(-0.32); space(p, after=3, before=0)
    run(p, f"{n}.  ", size=11, bold=True, color=BLUE)
    run(p, text, **{k:v for k,v in kw.items() if k in ("size","bold","italic","color","font")}); return p
```

### Rubric table pattern
Use a bordered table with hairline (#D8D2CC) borders. Header row filled BLUE with white text and `w:tblHeader` so it repeats on page 2. Criterion column filled TINT; put the Spanish criterion name in BLUE bold and the English under it in small grey italic. Each performance cell leads with its point range in a small gold-brown color, then the descriptor at ~8pt. Put `w:cantSplit` on each `w:tr` so a criterion row never splits across pages. Six columns fit landscape at ~0.6in margins (roughly: Criterio 1.85in, Pts 0.5in, four levels ~1.86in each).
